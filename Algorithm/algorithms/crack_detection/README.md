# 玻璃裂纹与自爆检测算法模块

## 1. 模块概述
本项目是一个基于传统计算机视觉（CV）的玻璃面板裂纹与自爆检测算法模块。算法主要通过图像处理技术提取边缘，并结合轮廓的几何特征规则来进行风险判定。当前代码已锁定为传统视觉特征分析模式，旨在提供一个逻辑清晰、易于调试的检测流水线。

## 2. 算法原理解析
算法流水线主要分为以下四个步骤：

1. **图像预处理 (`preprocessor.py`)**：
   * 尺寸统一：将输入图像缩放到指定尺寸，减少计算量。
   * 降噪处理：使用中值滤波去除图像中的噪点。
   * 灰度增强：将图像转换为灰度图后，进行灰度拉伸，增强裂纹与背景的对比度。
2. **边缘提取 (`feature_extractor.py`)**：
   * 采用 Canny 算子对预处理后的图像进行边缘提取，生成二值化的边缘图像。
3. **轮廓基础特征分析 (`feature_extractor.py`)**：
   * 对边缘图像提取连通轮廓，首先剔除面积过小的噪点轮廓。
   * 计算轮廓的核心几何参数：**形状因子 (圆形度的倒数)**、**宽高比**、**密实度**。
   * 只有满足特定几何参数阈值范围的轮廓，才会被认定为疑似裂纹。
4. **干扰特征过滤 (`feature_extractor.py`)**：
   * **网格/直线干扰**：计算轮廓的“凸包矩形度”，如果形状过于规则，接近矩形，则将其作为网格或电线干扰滤除。
   * **窗框干扰**：通过计算轮廓的实际厚度与多边形拟合的顶点数，以及轮廓的“凸包矩形度”（矩形度限制比网格/直线干扰更宽松），过滤掉粗大且顶点较少的 L型/U型 窗框边缘。

如果在经过所有过滤条件后，依然存在符合特征的轮廓，算法则判定为检测到玻璃裂纹/自爆。

## 3. 核心配置参数说明 (`config.py`)
所有算法的判定阈值与开关均在 `config.py` 中集中管理。维护者可根据实际测试场景的反馈调整这些参数：

### 图像处理参数
* `RESIZE_SIZE`: 统一输入图像的尺寸（默认 `(640, 480)`）, **⚠️ 建议使用默认尺寸**。
* `MEDIAN_FILTER_KERNEL`: 中值滤波的核大小，数值越大降噪越强，但可能模糊边缘。

### 轮廓基础特征阈值
* `MIN_CONTOUR_AREA`: 最小轮廓面积，低于此值的轮廓将被直接丢弃，用于忽略微小噪点。
* `SHAPE_FACTOR_THRESHOLD`: 形状因子上限阈值（通常裂纹边缘不规则，形状因子较小）。
* `ASPECT_RATIO_LOW` / `ASPECT_RATIO_HIGH`: 裂纹宽高比的合理区间。
* `SOLIDITY_LOW` / `SOLIDITY_HIGH`: 密实度区间，裂纹的轮廓通常密实度较低。

### 干扰过滤开关与参数
* `ENABLE_BOXINESS_FILTER`: 是否开启“凸包矩形度”过滤。
  * `BOXINESS_THRESHOLD`: 矩形度上限，超过该值认为是规则的人工网格。
* `ENABLE_FRAME_FILTER`: 是否开启“窗框”过滤。
  * `L_FRAME_THICKNESS_MIN`: 窗框最小厚度判定。
  * `L_FRAME_VERTEX_MAX`: 窗框最大多边形顶点数。
  * `L_FRAME_BOXINESS_MIN`: 窗框凸包矩形度下限.

### 调试与测试配置
* `IS_PRINT`: 设为 `True` 时，终端会打印每个轮廓的详细特征参数，适合调参时分析漏报或误报原因。
* `SAVE_CANNY_IMAGE`: 设为 `True` 时，会将生成的 Canny 边缘图保存到本地磁盘。
* `IS_MOVE_ERROR_SAMPLES`: 批量测试时，设为 `True` 可以将判定错误的样本（误报/漏报）从原测试集中移出到指定文件夹，方便集中复盘。

## 4. 算法局限性与使用建议
为了保证算法检测的准确性，使用者在采集图像时应注意以下几点：
1. **环境背景**：建议保持输入的照片背景干净。复杂的树影、建筑倒影或密集的外部装饰可能会产生干扰边缘，导致误报。
2. **拍摄角度**：尽可能**正对**玻璃幕墙拍摄。斜向拍摄会导致原本规整的玻璃形状在图像中发生透视形变，这会破坏宽高比和矩形度等几何特征的判定逻辑。

## 7. 运行与测试指南

### 单图调用 API
你可以通过实例化 `GlassBreakageAlgorithm` 直接进行单次检测：
```python
from crack_detection.breakage_algorithm import GlassBreakageAlgorithm

algorithm = GlassBreakageAlgorithm()

# 传入本地图片路径
result = algorithm.run(image_input="./test_images/sample.jpg")

print(result)
# 输出格式示例：
# {'status': 'error', 'title': '自爆确认', 'description': '[传统 模式]检测到玻璃裂纹特征', 'details': [...]}
```

### 批量测试与精度评估
在准备好包含正常与异常图像的数据集后，可运行批处理脚本来统计算法的综合指标。
```bash
python -m crack_detection.batch_test
```
* **功能说明**：脚本会遍历 `datasets/test_cases/images` （路径可在`batch_test.py` 中修改）下的图片，与 `labels` 中的标注结果进行对比。最终输出包含 `TP, TN, FP, FN` 以及准确率、召回率、精确率和 F1 得分的统计面板。
* **错例收集**：如果开启了 `IS_MOVE_ERROR_SAMPLES`，误报（FP）和漏报（FN）的图片及标签会被自动移动到 `remove` 文件夹中。
